# Voicebox CLI Harness

This fork includes a CLI-Anything harness and Open Agent Skill in [`voicebox-cli/`](voicebox-cli/).

Start there for:

- installing `cli-anything-voicebox`
- installing the `voicebox-cli` agent skill
- setting up the local Voicebox backend
- generating speech with Kokoro or other Voicebox engines from agent workflows

The fork preserves upstream Voicebox history. The CLI package is intentionally isolated in `voicebox-cli/` so upstream app changes can still be pulled and merged normally.
